## Public CLI and state assertions

The harness built `./cmd/sow` with `CGO_ENABLED=0` and invoked only public V2
commands. Every response parsed as one JSON document with schema
`sow.cli/v1`, `ok: true`, and an empty `errors` array. It additionally checked:

- `init` created the requested Workspace and reported zero pre-existing
  Repository or Dist objects;
- `repo new local` selected Repository `local`, reported clean empty state,
  and returned the fixed path `<workspace>/local`;
- `dist new el9 --format rpm` projected canonical families to RPM
  `x86_64` and `aarch64`;
- `dist new noble --format deb` projected the same families to DEB `amd64`
  and `arm64`;
- `config check` reported exactly one Repository and two Dists;
- `dist ls` returned exactly `el9/rpm` and `noble/deb` in stable order;
- the per-Repository SQLite file existed at `.sow/local.db`.

All generated Dists were clean and empty. The RPM views contained unsigned
`repodata/repomd.xml`. The DEB view contained `Release` plus byte-empty
`Packages` and valid gzip streams that decompressed to byte-empty content for
both architectures. No `repomd.xml.asc`, `InRelease`, or `Release.gpg` file was
present under the unsigned default.
