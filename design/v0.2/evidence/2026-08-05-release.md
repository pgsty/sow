Scope: current `codex/release-v0.2.0` checkout, local build and local Git seal

## Result

The top-level `make release` target completed successfully after running its
gates in order:

1. gofmt check, `go mod tidy -diff`, `go vet`, staticcheck, and focused v0.2
   package tests;
2. non-cached `go test -timeout 60m -count=1 ./...`;
3. the nested `third_party/cavaliergopher-rpm` test suite;
4. edge bundle regeneration check and all 49 Node contract tests;
5. race-detector tests for `internal/v2/...`, `internal/v2cli`, APT, and YUM;
6. deterministic clean delivery from two independent fresh extractions;
7. four static release builds and `SHA256SUMS` generation.

The clean-delivery run used `goproxy.cn` and `sum.golang.google.cn` because the
default Google endpoints timed out from the acceptance host. Checksum database
verification remained enabled; this changed transport only, not the module or
checksum policy.

## Corrections found by the gate

- Cross-build validation initially assumed Go 1.26 exposed linker `-X` values
  through `go version -m`; the Makefile now validates actual GOOS/GOARCH, while
  executable and unit tests bind the release version.
- Clean delivery found a stale `0.2.0-dev` assertion and was updated to the
  released version.
- The first full test found a V1 migration test coupled to the root README. The
  retained V1 contract is now checked in internal design/runbook material, so
  the v0.2 README can describe the active command surface.

All three corrections were followed by focused regression tests, then by the
successful end-to-end `make release` run above.

## Workspace and publication boundary

Finder files, IntelliJ metadata, and generated `.memlog.md` files were moved to
the macOS Trash rather than deleted permanently. Public documentation was not
changed; it is owned by the separate `sow.pgsty.com` checkout. Internal v0.2
design and evidence live under `design/`.

The release is sealed with the local annotated tag `v0.2.0` after this evidence
is committed. No remote is configured, and no push, upload, or public release
is part of this acceptance.
