# SOW design documentation

The maintained design authority is the bilingual
[SOW Design documentation](https://sow.pgsty.com/docs/design/).

This source directory intentionally contains only this pointer. Historical
design inputs, specifications, reviews, and evidence remain available from Git
history and version tags. They retain their original evidence boundary and are
not maintained documentation.

Do not rewrite an old result to match a new implementation. Update the
maintained site documentation and record the behavior in the release changelog.
