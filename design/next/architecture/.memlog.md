- (constraint) Inherit Repository ownership, root-bound path safety, parser-renderer separation, pointer-last publication, canonical architecture, and local transaction boundaries from v0.2.
- (decision) AD-13 is amended for the next design: RPM metadata computes a parent-relative href from each view root to the canonical root pool; the v0.2 C2 view-local hardlink rule is retired.
- (decision) The deduplication and GC reachability boundary is exactly one Repository and one publish prefix, not the workspace, bucket, account, or all targets.
- (decision) A Repository root is the relocation, mirror, authorization, and publication unit; a dists leaf or RPM architecture view is not standalone.
- (decision) Canonical publication maps pool and dists paths one-to-one to object keys; no URL router, absolute xml:base, redirect object, or hardlink alias is required for correctness.
- (decision) Hardlinks remain allowed only in private transactional recovery, APT by-hash metadata, and explicit disposable external exports; copy is the export default.
- (decision) Default EL reposync is unsupported; safe-write-path is best effort only, and standalone mirroring uses whole-root copy or explicit export.
- (decision) Snapshot-like views add metadata and a retained digest set only; package payloads remain at canonical pool paths and GC uses repository-wide reference closure plus stale-client grace.
- (decision) Check validates href resolution, containment within the Repository, digest, size, membership, and manifest closure; SameFile and link count are never package correctness checks.
- (decision) Repository Built Generation and Changeset are target-neutral; Publication Attempt, Applied Checkpoint, inventory, grace, and delete evidence are target-prefix scoped.
- (decision) Direct static publication has per-view commit units: persist forward-only commit intent before the first pointer update, roll every view forward with remote CAS, then record the target checkpoint.
- (decision) Public paths use the versioned sow-managed-pool-v1 ASCII grammar and deterministic uppercase percent encoding; view base URIs are trailing-slash directories.
- (decision) The only initial standalone RPM export profile is sow-rpm-leaf-v1; copy is default and hardlink mode requires a trusted read-only boundary and exits hostile-writer guarantees.
- (decision) C2 migration uses a separate c2-to-single-v1 transition journal; changes, ordinary publish, and GC fail closed until aliases are receipt-deleted and a terminal next Generation is committed.
